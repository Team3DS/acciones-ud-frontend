> ### `Sobre el repositorio`

Frontend de **Acciones UD**, la plataforma web responsiva de Day Trading para el mercado colombiano que desarrolla el equipo [Team3DS](https://github.com/Team3DS). Interfaz para inversionistas, comisionistas y administradores: órdenes, portafolios, watchlists y reportes.

> ### `Stack`

1. React con TypeScript.
2. Vite como empaquetador y servidor de desarrollo.
3. Alias `@` hacia `src` para importaciones cortas.

> ### `Estructura`

```
public/
src/
├── assets/
├── components/
├── features/
├── hooks/
├── pages/
├── services/
├── store/
├── styles/
├── types/
└── utils/
```

> ### `Puesta en marcha`

Estado inicial: configuración y estructura base, sin componentes de aplicación todavía.

1. Prerrequisitos: Node LTS con corepack habilitado.
2. Instalar dependencias: `corepack pnpm install`.
3. Servidor de desarrollo: `corepack pnpm dev`, disponible a partir del primer sprint cuando se incorpore la plantilla de arranque.
